# Subham E — Netflix-inspired Career Portfolio

## Viewing flow
1. `index.html` — animated SE logo intro.
2. `profiles.html` — choose HR, Hiring Manager, Friend, or Family.
3. `portfolio.html` — personalized career portfolio overview.

## Portfolio pages
- `portfolio.html` — profile, professional summary, career highlights, work timeline, capabilities, tools, education, languages, and contact links.
- `experience.html` — detailed work experience and responsibilities.
- `projects.html` — representative case files with category filters and detail modals.
- `skills.html` — core capabilities and tool stack.
- `contact.html` — email, phone, LinkedIn, and contact form that prepares an email draft.

## Run locally
Keep all files and the `assets` folder together. Open `index.html` in a browser. The intro advances automatically; Skip Intro moves to profile selection.

## Publish on GitHub Pages
1. Create a repository, e.g. `subham-portfolio`.
2. Upload all files and the complete `assets` folder.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/(root)` → Save.
5. Open the URL GitHub Pages provides.

## Before publishing
Verify résumé details and contact information. This is a static site with no backend. The contact form opens an email draft and does not submit data to a server. Case files are representative process examples, not confidential client deliverables.


## Photo troubleshooting
Keep `assets/subham-headshot.png` in the same published folder structure as `portfolio.html`. The portfolio also includes an embedded fallback portrait, so the image remains visible if the asset folder is accidentally omitted.
